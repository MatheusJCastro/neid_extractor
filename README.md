# NeidExtractor

[![GitHub Release](https://img.shields.io/badge/github-repo-blue?logo=github)](https://github.com/MatheusJCastro/neid_extractor)

*Written by: Matheus J. Castro*  
*Under MIT License* 

This library can work with NEID spectrum files level 2.

For usage example, see [Basic Usage](examples/basic_usage.ipynb).

## Install

It is recommended to use a python environment for this.

Install the package using pip directly from GitHub:

```bash
pip install git+https://github.com/MatheusJCastro/neid_extractor.git
```

And, to uninstall it:

```bash
pip uninstall neid_extractor
```
